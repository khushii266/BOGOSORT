# Mission Control – Launch Watcher

A web-based mission control dashboard that provides launch information, mission settings, and launch tracking features.

## Features

- Displays the next launch window
- Shows mission and orbit information
- Provides mission control settings
- Interactive launch tracking interface
- Responsive web interface

## Technologies Used

- HTML
- CSS
- JavaScript
- Python
- Flask

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Run the Python server:

```bash
python server.py
